# English and Korean presentation

The shared `frontend/src/app/i18n` provider and typed English/Korean JSON catalogs localize existing pages. Static labels use `LocalizedText` message keys. Dynamic API labels and known errors resolve centrally through catalog aliases and interpolation templates; unknown values remain visible unchanged. Raw API objects, chart data keys, formulas, symbols, and calculations are not translated.

The root layout reads `mri_ui_language` (English by default). The shared header changes React context and saves a one-year, root-path SameSite=Lax cookie, with Secure on HTTPS. Refresh, navigation, and login/logout preserve this cookie independently of authentication. Server metadata and HTML language follow the selected locale.

`useI18n()` supplies `t` and the Intl locale. Monetary formatting preserves USD/KRW accounts and numerical values; KRW has no fractional digits. Display dates use Intl; ISO data keys remain unchanged. Korean fonts are self-hosted under `public/fonts`, with their OFL license.

To add copy, add matching keys in both catalogs, preserving interpolation parameters. Use `LocalizedText id` for static text and `t` for string-only component properties. Never wrap Recharts series elements in translation components. Run `node tests/i18n.test.cjs`, TypeScript, and the production build. The test checks key/parameter parity, symbols/formulas, dynamic errors, and static JSX coverage.

A future Advisor can use a separate conversation language setting; this provider controls presentation only and does not implement an Advisor.
