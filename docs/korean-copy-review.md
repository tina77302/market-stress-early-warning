# 한국어 UI 문구 검토 — 2026-10-14

현재 `wip/data-automation` 브랜치의 화면 문구만 정리했습니다. 기존 한국어 문구 751개를 검토해 435개를 수정하고, 빠진 표시 문구와 문장 템플릿 61개를 추가했습니다. 기존 영어 문구 751개는 모두 유지했습니다. 두 언어의 중앙 카탈로그는 각각 812개 항목입니다.

- `frontend/src/app/admin/page.tsx`: 지표·제공 기관·오류 내용 번역 연결, 상태와 표 머리글 구분
- `frontend/src/app/components/DataHealthNotice.tsx`: 지표명 번역 연결, ERROR 상태 번역 키 명시
- `frontend/src/app/components/CrossMarketSnapshot.tsx`: 비교 표의 ERROR 상태 번역 키 명시
- `frontend/src/app/components/MethodologyOverview.tsx`: 끊어진 문장을 완성형 템플릿으로 묶어 한국어 어순 반영

- `frontend/tests/i18n.test.cjs`: 한국어 품질·키·숫자·양 언어 렌더링 검사 보강
- `docs/korean-copy-review.md`: 검토 결과 기록

모델, 수식, 입력 변수 정의, 기준값, 시장 데이터 자동화, 최신 상태 판정, API, 인증, 모의투자·관리자 업무 로직, 경로, CSS, 번역 엔진·Provider는 수정하지 않았습니다. 앞선 자동화 작업의 미커밋 변경도 유지했습니다. 필수 빌드에서 생성된 `frontend/tsconfig.tsbuildinfo`는 이번 작업 시작 전 내용으로 복원했습니다. 커밋·푸시는 하지 않았습니다.

## 3. 개선 예시

| 기존 문구 | 정리한 문구 |
| --- | --- |
| 시장 리스크 인텔리전스 | 시장 위험 분석 |
| 위험을 순증가시키는 요인 | 위험을 높이는 요인 |
| 정수 주식 수량 | 주문 수량 (주) |
| 10거래일 표본외 성능 | 10거래일 OOS 검증 결과 |
| 조회 가능한 주요 기여 요인 | 주요 기여 요인 |
| 약 1거래 월 | 약 1개월 (거래일 기준) |
| 모의투자 작업 공간 | 나의 모의투자 |
| 최근 활동 / 주문 내역 | 거래 내역 |

주문 요약은 `BUY 3 shares of SPY.`를 ‘SPY 3주 매수’로 표시합니다. 영어는 그대로 유지합니다. MSI 구성·분석 한계 설명은 짧은 번역 조각을 이어 붙이는 대신 완성형 문장 템플릿으로 처리했습니다. SHAP 기여도에서도 ‘신용 252D ZScore’ 대신 ‘신용 스프레드 252거래일 Z-Score’로 표시합니다. 원래 모델 변수 식별자는 바꾸지 않습니다.

## 4. 데이터 최신 상태

| 실제 상태 | 화면 문구 |
| --- | --- |
| CURRENT | 최신 데이터 반영 |
| DELAYED | 일부 지표 업데이트 대기 |
| STALE | 데이터 갱신 필요 |
| PARTIAL | 일부 데이터 확인 필요 |
| ERROR | 데이터 업데이트 오류 |

시장 위험 분석에 쓰는 지표 상태라는 점을 ‘시장 위험 데이터 기준일’, ‘분석 지표별 최신 상태’로 명시했습니다. 일부 신용 지표의 발표 대기를 주가 지연으로 표현하지 않습니다. 데이터 수집 시각은 별도로 표기합니다. 상태값이나 `is_current` 판단은 그대로입니다.

기존 번역 엔진은 대소문자를 구분하지 않아 `ERROR`와 표 머리글 `Error`가 같은 별칭으로 처리됩니다. 상태 표시에는 기존 `error_data_health` 키를 명시해 ‘데이터 업데이트 오류’로, 표 머리글은 ‘오류 내용’으로 구분했습니다. 번역 엔진은 바꾸지 않았습니다.

## 5. 모의투자

예수금, 총 평가금액, 보유 종목, 수량 (주), 평균 매입가, 최근 확정 종가, 평가금액, 평가손익, 실현손익, 주문 가능 금액, 매도 가능 수량, 매수·매도, 거래 내역을 사용합니다.

모의투자는 가상 자금과 확정 종가를 사용한다는 설명을 유지했습니다. 가격 표시는 ‘모의투자 가격 기준 시각’, 시장 위험 결과는 ‘시장 위험 데이터 기준일’로 구분합니다. 가격 확인 요청의 2분 유효시간은 종가 자체의 최신 상태가 아니라 ‘이 가격으로 주문 가능한 시간’으로 표현했습니다. 실제 거래나 실시간 가격으로 오인할 만한 표현은 사용하지 않습니다.
